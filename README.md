## 📌 Project Overview

The Healthcare Analytics Dashboard is a comprehensive Power BI solution designed to analyze hospital operations, provider performance, financial health, and healthcare service utilization. The dashboard combines provider-level and hospital-level metrics to deliver actionable insights into workforce productivity, CPT unit distribution, revenue cycle performance, specialty analysis, and regional healthcare trends.

The solution enables healthcare administrators and decision-makers to monitor key performance indicators, identify operational inefficiencies, evaluate provider effectiveness, and optimize resource allocation through interactive and data-driven visualizations.

### Dashboard Modules

#### 🩺 Healthcare Provider Metrics
- Provider count and workforce analysis
- Specialty-wise provider distribution
- Regional physician performance
- Monthly provider activity and CPT utilization
- Provider FTE and productivity metrics

#### 🏥 Hospital Performance Overview
- Hospital financial performance monitoring
- Accounts receivable analysis
- CPT procedure volume tracking
- ARGE and IPTP ratio trend analysis
- Hospital-wise CPT unit distribution
- Regional healthcare performance insights

### Key Business Value
- Improve healthcare operational efficiency
- Monitor provider productivity and resource utilization
- Support financial decision-making
- Track hospital performance across regions
- Enable data-driven healthcare management
